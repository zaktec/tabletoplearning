# TableTopLearning Human-Friendly Web App Guide

## About this guide

This guide explains TableTopLearning in clear, non-technical language. It is intended for clients, learners, parents, carers and other stakeholders who want to understand what the website offers and how people use it.

For implementation details, see [technical-reference.md](technical-reference.md). For logo, colour, writing and presentation rules, see [branding.md](branding.md).

## What TableTopLearning does

TableTopLearning is a website for exploring structured online courses and tutor-supported learning.

It brings the main information into one place so visitors can:

- Browse subject areas.
- Understand different learning pathways.
- Read course summaries.
- Compare levels of tutor support.
- Find answers to common questions.
- Contact TableTopLearning about courses or support.

The website is currently focused on helping people explore and compare options. It does not yet deliver lessons or manage active learner accounts.

## Who the website is for

### Learners

Learners can explore subjects, compare course levels and understand how weekly learning and tutor support are presented.

For example, someone interested in coding can follow the Python pathway from foundations through problem-solving and projects.

### Parents and carers

Parents and carers can review course information, compare support plans and understand what guidance may be available before making an enquiry.

For example, a parent can compare independent learning with plans that show more frequent tutor contact.

### People returning to learning

The site includes references to Functional Skills, examination preparation and different course levels. This helps visitors identify a possible starting point before contacting the team.

### Prospective clients and partners

The About, safeguarding, privacy and contact pages provide a clear overview of the organisation and its public information.

## Main features

### Subject directory

The homepage always displays six subject cards:

- Maths.
- Computing & AI.
- Science.
- English.
- Religion.
- Languages.

Related subjects are grouped to keep the homepage concise. Religion and Languages remain separate and always occupy the final two positions. Available subject cards link to more information; subjects still being prepared show a non-clickable status.

Current availability shown on the homepage:

| Subject | Displayed status |
| --- | --- |
| Maths | Available to explore |
| Computing & AI | Available to explore |
| Science | Courses coming soon |
| English | Courses coming soon |
| Religion | Courses coming soon |
| Languages | Courses coming soon |

“Coming soon” labels help visitors distinguish current information from future course areas.

### Short modules and learning pathways

The homepage explains the learning model as:

**Short Modules → Learning Pathways → Qualification Preparation**

The homepage provides a short explanation and links to dedicated Modules and Learning Pathways pages. The Modules page shows five example starting topics. The initial pathways are:

- GCSE Foundation Maths.
- GCSE Higher Maths.
- Python Coding.
- Problem Solving.
- Artificial Intelligence.

The Learning Pathways page shows an example progression through related modules. Available pathways link to an existing subject page; unfinished destinations are shown as coming soon and are not linked.

### Course pages

Course pages provide short summaries, feature lists and links back to the wider catalogue or subject directory.

They are useful for exploring the type and focus of a course. They do not contain full lesson material, enrolment or progress tracking.

### Support-plan comparison

The Support page compares three support levels:

| Plan | Displayed price | Simple description |
| --- | ---: | --- |
| Independent Learning | £19 per month | Structured independent learning with light tutor monitoring |
| Tutor Guidance | £49 per month | More regular guidance, including one live lesson each month |
| Focused Support | £89 per month | More frequent support, including two live lessons each month |

These prices and features are shown for comparison. The website does not currently take payment or start a subscription. Availability and current terms are confirmed separately.

### Frequently asked questions

The Support page includes expandable answers about:

- Completing modules separately.
- Understanding learning pathways.
- GCSE qualification boundaries.
- Initial pathway availability.
- Tutor support and flexible study.

Visitors can open and close each answer without leaving the page.

### Contact form

The Contact page includes fields for:

- Full name.
- Email address.
- Enquiry topic.
- Message.

Selecting **Prepare email** opens the visitor’s email application with a message addressed to TableTopLearning. The visitor can review the message before sending it.

The website itself does not store the form details or send the message automatically.

### Public information pages

- **About** explains the organisation and its approach.
- **Privacy** explains how to make a privacy enquiry.
- **Safeguarding** gives the safeguarding contact route and emergency guidance.
- **Learner Login** clearly explains that account access is not yet available.

## How people use the website

### Example 1: A learner exploring Maths

1. Open the homepage.
2. Select the Mathematics subject card.
3. Review the available course descriptions.
4. Open the Support page to compare guidance options.
5. Use the Contact page to prepare a question about the right starting level.

### Example 2: A parent comparing support

1. Read the homepage overview.
2. Open Support and compare Independent Learning, Tutor Guidance and Focused Support.
3. Open the FAQs for quick answers.
4. Read safeguarding or privacy information if needed.
5. Contact TableTopLearning with a specific course or support question.

### Example 3: A learner interested in coding

1. Select Computer Science from the subject directory.
2. Review the Python and Computer Science information.
3. Open Modules and Learning Pathways to review the Python examples and progression.
4. Prepare an enquiry if more guidance is needed.

## Benefits for visitors

### Clear choices

Subjects, pathways and support levels are separated into scannable sections, making it easier to compare options.

### Structured progression

The site explains learning as a sequence of manageable steps rather than an unstructured collection of resources.

### Visible support levels

Visitors can see how independent learning and tutor-supported options differ before making contact.

### Honest availability

Coming-soon labels and the login placeholder make it clear which parts are informational and which parts are not yet available.

### Easy contact

Visitors can prepare a detailed email from a simple form or use the direct email address.

### Mobile-friendly access

Pages, navigation, cards and forms adapt to smaller screens so the site can be used on phones, tablets and desktop computers.

## What the website does not currently do

To avoid confusion, the following services are not currently available through the website:

- Creating an account.
- Signing in to a learner dashboard.
- Completing lessons or quizzes online.
- Saving course progress.
- Enrolling or paying online.
- Booking live lessons.
- Messaging a tutor inside the website.
- Sending the contact form directly without an email application.

These may be future possibilities, but they should not be treated as confirmed features.
