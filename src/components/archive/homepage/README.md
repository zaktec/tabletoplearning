# Archived homepage content

This directory contains homepage content that is no longer rendered by the active TableTopLearning homepage.

## Archived files

### `HomepageBeforeModules.astro`

A complete snapshot of the previous homepage, including:

- The former course and pathway sections.
- The separate Python coding pathway.
- The previous “How it works” content.
- The repeated course-feature and tutor-support panel.
- The previous pricing, trust, FAQ and final call-to-action content.

## Why it was archived

The homepage was reorganised to explain the primary learning model more clearly:

```text
Short Modules → Learning Pathways → Qualification Preparation
```

Repeated content was removed from the live page so each important idea has one main section.

27 July 2026.

## Future use

The archived content may be reviewed or selectively reused later. It is not imported by the active homepage and should not be restored without checking the current product scope, brand guide and accessibility requirements.
